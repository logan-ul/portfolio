This service connects the Duck project to NFC cards. It is designed around writing project information to a duck so that the duck can act as a simple, portable link to a duck’s stored data. This required some learning about how smart cards work.

Legacy hardware / investigation

2003 Hikvision Camera Project

This project explores a 2003 Hikvision camera and the process of working with older hardware. It was a fun way to exercise research, compatibility testing, troubleshooting, and finding practical ways to understand technology that was built for a different era. The plan was to incorporate the camera into a school club, but that never panned out, and thus, the project was abandoned.
