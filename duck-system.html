Duck API/System

You know how key cards work? Thats pretty similar to what this project was about. As a part of the Computer Programming class at ECTS we can earn these prizes known as "Duck Pieces." With enough of these pieces we can eventually put together a Duck. Once a student put together a duck, a chip could then be glued to the bottom and information about said duck would be applied.

My part in this project centers around the actual storage of all this information. The picture you see with the "Request a Duck" form details all the information students had to fill out. I helped design and create this website that would take this information, store it in a database, and write the api link to the chip on the bottom of the duck.

What made this extra cool is that the little readers, that would accept a duck you might place on it, gave back information directly from the api. This meant that other people in the class room could:

  1. Put together a duck
  2. Fill out a form with all of its information
  3. Write that information to the duck's chip
  4. Use or request that information in other later applications through a simple link
