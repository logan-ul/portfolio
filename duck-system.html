Duck API & NFC System

A connected system for storing duck information and making it available through NFC.

The gallery shows the admin dashboard, request form, and API documentation for this project.

A key card is a useful comparison: this project stores information on a small, scannable device. As part of the Computer Programming class at ECTS, students can earn prizes known as "Duck Pieces." With enough pieces, we can assemble a duck. Once a student builds one, an NFC chip can be attached to the bottom and programmed with information about it.

My part in this project focuses on storing and managing that information. The "Request a Duck" form shows the details students had to submit. I helped design and create the website that accepts this information, stores it in a database, and writes the API link to the chip on the bottom of the duck.

What made this extra cool is that small readers can accept a duck and return information directly from the API. This means that people in the classroom can:

  1. Put together a duck.
  2. Fill out a form with its information.
  3. Write that information to the duck's chip.
  4. Use that information in other applications through a simple link.
