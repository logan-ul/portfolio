Task Assessment Tool

A classroom tool for tracking programming skills and practical assessments.

Each lab at ECTS has a set of standards each student should be able to meet. These requirements are program specific. My teacher assigned me this project as something a senior who had graduated hadn't had time to complete. It's an application that takes a list of skills that students should be able to complete and uses AI to come up with a small assignment that tests that skill. It then also scores that response using AI, with things like a 1-10 grade and explanation.

This Project helped me get used to working with databases, and Microsoft Azure. Essentially the user must use their Microsoft school account to sign into the application. It also stores all the students responses, scores, and explanations.
